# Mục lục tài liệu

Đọc [Brief](product/brief.md) để hiểu bài toán, [PRD](product/prd.md) để triển khai chức năng và tiêu chí nghiệm thu, rồi [kế hoạch đồ án](planning/project-plan.md) để theo lộ trình nghiên cứu 12 tuần.

| Nhóm | Nội dung |
|---|---|
| [product](product/prd.md) | Brief và PRD của toàn sản phẩm |
| [planning](planning/project-plan.md) | Kế hoạch tổng; [planning/mvp](planning/mvp/README.md) là kế hoạch MVP G2 riêng |
| [design](design/README.md) | Thiết kế và luồng sử dụng; prototype nằm trong `design/` ở gốc repo |
| [development](development/project-structure.md) | Cấu trúc repo và [thiết lập GitHub](development/repository-setup.md) |
| [implementation/mvp](implementation/mvp/README.md) | Bàn giao và bằng chứng kỹ thuật của MVP v1 theo từng phần |
| [implementation/curriculum](implementation/curriculum/grounding.v1.md) | Registry/pilot, Analyzer, KG/RAG và hướng dẫn Colab embedding |
| [research/data](research/data/README.md) | Kiểm kê dữ liệu nghiên cứu và báo cáo tổng hợp |

RAG pilot mới: [Qwen query catalog trên Kaggle + pgvector](implementation/curriculum/rag-runtime.v1.md), tiếp nối [kết quả Qwen Kaggle](research/retrieval/qwen3-4b-v1.md). Bản này vẫn là preview có xác thực; nội dung chưa duyệt không trở thành nội dung học công bố.

Các tài liệu bàn giao MVP ghi trạng thái tại thời điểm triển khai từng phần. Khi tìm cách chạy bản hiện tại, bắt đầu từ [README sản phẩm](../README.md).
