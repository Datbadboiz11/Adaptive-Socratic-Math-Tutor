# Bàn giao MVP v1

Đây là tài liệu triển khai và evidence của MVP một chủ đề. [PRD](../../product/prd.md) và [kế hoạch tổng](../../planning/project-plan.md) vẫn quy định phạm vi đồ án đầy đủ.

| Phần | Nội dung |
|---|---|
| [phase1](phase1/README.md) | Phạm vi, nội dung mẫu, contract và khung môi trường |
| [phase2](phase2/README.md) | API, PostgreSQL, session và persistence |
| [phase3](phase3/README.md) | Validator toán, observation/BKT, LangGraph và OpenAI |
| [phase4](phase4/README.md) | Giao diện tích hợp và các trạng thái thao tác |
| [phase5](phase5/README.md) | Kết quả kiểm thử và trạng thái manual evidence |

Các phiếu bàn giao/evidence giữ trạng thái của lần chạy đã ghi. Việc sắp xếp thư mục không tự đổi ca chưa chạy thành PASS.
