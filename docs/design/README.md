# Thiết kế và prototype

Prototype độc lập vẫn nằm trong [design/](../../design/README.md) ở gốc repo; frontend sản phẩm đang chạy nằm trong `frontend/`.

- [Đặc tả giao diện](../../design/DESIGN_SPEC.md): màu sắc, bố cục, component và trạng thái.
- [UI flow](../../design/USER_FLOWS.md): hành trình học và các ngoại lệ.
- [Cách mở prototype](../../design/README.md): trang HTML dùng dữ liệu mô phỏng.
- [Bàn giao giao diện tích hợp](../implementation/mvp/phase4/README.md): hành vi dùng API và giới hạn hiện tại.

Spec và UI flow của prototype được giữ cùng mã HTML để tra cứu trong một nơi. PRD của sản phẩm nằm tại [docs/product/prd.md](../product/prd.md).
