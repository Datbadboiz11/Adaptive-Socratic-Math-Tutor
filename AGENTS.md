\# Autonomous Coding Rules



Work autonomously.



\- Do not ask for confirmation before normal coding operations.

\- Inspect the relevant code first.

\- Make a short plan before implementation.

\- Execute the plan automatically.

\- Create and modify files as needed.

\- Run tests, builds, linting, type checks, and debugging automatically.

\- Fix errors automatically and continue until the task is complete or genuinely blocked.



\## Forbidden actions



\- NEVER delete any file or folder without asking the user first.

\- NEVER run `git commit`.

\- NEVER run `git push`.

\- NEVER run `git reset --hard`.

\- NEVER run `git clean`.

\- NEVER discard or overwrite unrelated user changes.

\- NEVER revert existing work unless explicitly requested.



If deleting a file or folder is necessary, stop and ask the user for permission first.



Do not repeatedly ask whether to proceed with normal code edits or commands.
